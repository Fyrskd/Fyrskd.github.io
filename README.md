# CF 引理/定理浏览器

这是从 `cf-knowledge/lemma-browser` 单独提取的离线静态页面包。

## 使用方式

直接用浏览器打开：

```text
index.html
```

不需要本地服务，不需要联网。

## 文件说明

- `index.html`：页面入口
- `styles.css`：页面样式
- `app.js`：搜索、筛选、排序和详情交互
- `data.js`：引理/定理索引数据快照

## 数据快照

- 扫描题目：938
- 引理/定理条目：147
- 唯一引理/定理：60
- 有引理/定理的题目：108

## 中文化说明

页面展示使用中文引理/定理名、中文结论表述和中文说明；`data.js` 中保留 `original_lemma_name` 仅用于追溯和搜索，不在页面中展示。原始题解摘录保留为“原文证据”。
